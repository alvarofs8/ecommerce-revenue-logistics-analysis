# Data Dictionary & Analytical Schema Reference

This document details the architecture, table structures, column definitions, and business logic across the three layers of the project:
1. **Raw Relational Layer (`public` schema)** – Source tables ingested from the [Olist Kaggle Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
2. **Intermediate Cleaning & Analytical Layer (`analytics` schema)** – Data cleansing, RFM scoring, and cohort retention views.
3. **Presentation Star Schema Layer (Power BI Semantic Model)** – Kimball dimensional model (`Fact` and `Dim` tables).

---

## 1. Presentation Layer: Power BI Star Schema

### 1.1 Fact Table: `Fact_Order_Items`
* **Source SQL View:** `analytics.vw_pbi_fact_orders`
* **Granularity:** One row per individual item sold within a delivered order (`order_id` + `order_item_id`).

| Column Name | Data Type | Description & Business Rule |
| :--- | :--- | :--- |
| `order_id` | `VARCHAR(32)` | Unique order identifier (used for order-grain deduplication in DAX). |
| `order_item_id` | `INT` | Sequential number identifying the item position within the same order (`1, 2, 3...`). |
| `customer_id` | `VARCHAR(32)` | Foreign Key to `Dim_Customers[customer_id]`. |
| `seller_id` | `VARCHAR(32)` | Foreign Key to `Dim_Sellers[seller_id]`. |
| `product_id` | `VARCHAR(32)` | Foreign Key to `Dim_Products[product_id]`. |
| `purchase_date` | `DATE` | Order purchase date cast from timestamp. Foreign Key to `Dim_Calendar[Date]`. |
| `delivery_date` | `DATE` | Actual date the order was delivered to the end customer. |
| `estimated_delivery_date` | `DATE` | Promised SLA delivery date communicated to the customer at checkout. |
| `order_status` | `VARCHAR(30)` | Filtered strictly to `'delivered'` orders with non-null delivery dates. |
| `actual_delivery_days` | `NUMERIC` | Days elapsed from purchase to actual delivery (`delivery_date - purchase_date`). |
| `delivery_variance_days` | `NUMERIC` | SLA variance (`delivery_date - estimated_delivery_date`). Negative values indicate early delivery ahead of SLA. |
| `item_price` | `DECIMAL(10,2)` | Unit price of the product (in BRL / R$), excluding freight. |
| `freight_value` | `DECIMAL(10,2)` | Shipping cost allocated to the specific order item (in BRL / R$). |
| `total_item_value` | `DECIMAL(10,2)` | Total gross revenue generated by the item (`item_price + freight_value`). |

### 1.2 Dimension Table: `Dim_Customers`
* **Source SQL View:** `analytics.vw_pbi_dim_customers`
* **Granularity:** One row per order-specific `customer_id`, enriched with lifetime behavioral RFM metrics linked via `customer_unique_id`.

| Column Name | Data Type | Description & Business Rule |
| :--- | :--- | :--- |
| `customer_id` | `VARCHAR(32)` | Primary Key for order-level joins to `Fact_Order_Items`. |
| `customer_unique_id` | `VARCHAR(32)` | True unique identifier of the physical customer across multiple orders. |
| `customer_city` | `VARCHAR(100)` | Standardized customer city name (`LOWER(TRIM(...))`). |
| `customer_state` | `VARCHAR(5)` | Two-letter Brazilian state code (`UPPER(...)`, e.g., `SP`, `RJ`, `MG`). |
| `customer_zip_code_prefix` | `VARCHAR(10)` | First 5 digits of the customer postal code. |
| `customer_segment` | `TEXT` | Behavioral RFM classification (`Champions`, `Loyal Customers`, `Recent New Customers`, `At Risk (Churning)`, `Lost One-Timers`, `Regulars/Others`, or `Unsegmented`). |
| `recency_days` | `NUMERIC` | Days elapsed between the customer's last purchase and the dataset's maximum date. |
| `frequency` | `BIGINT` | Total distinct delivered orders placed by `customer_unique_id`. |
| `monetary` | `DECIMAL(10,2)` | Total lifetime payment value (`SUM(payment_value)`) across all orders of the customer. |
| `customer_region` | `TEXT` | Brazilian macro-region grouping (`Southeast`, `South`, `Northeast`, `Central-West`, `North`). |

**Macro-Region Mapping Logic (`customer_region`):**
* **Southeast:** `SP`, `RJ`, `MG`, `ES`
* **South:** `PR`, `SC`, `RS`
* **Northeast:** `BA`, `PE`, `CE`, `MA`, `PB`, `RN`, `PI`, `AL`, `SE`
* **Central-West:** `DF`, `GO`, `MT`, `MS`
* **North:** `AM`, `PA`, `RO`, `TO`, `AC`, `AP`, `RR`

### 1.6 Disconnected Analytical Table: `Cohort_Retention`
* **Source SQL View:** `analytics.vw_cohort_retention` (`04_cohort_analysis.sql`)
* **Granularity:** One row per acquisition month (`cohort_month`) and relative return month (`month_index`).

| Column Name | Data Type | Description & Business Rule |
| :--- | :--- | :--- |
| `cohort_month` | `DATE` | First purchase month (`DATE_TRUNC('month', MIN(order_purchase_timestamp))`) of the customer cohort. |
| `total_cohort_users` | `BIGINT` | Total distinct customers acquired in `cohort_month` (Month 0 baseline). |
| `month_index` | `INT` | Number of months elapsed since first purchase (`0, 1, 2 ... 12+`). |
| `active_customers` | `BIGINT` | Distinct customers from the original cohort who placed an order in `month_index`. |
| `retention_rate` | `NUMERIC(5,2)` | Percentage of returning customers (`ROUND(active_customers * 100.0 / total_cohort_users, 2)`). |

## 2. Analytical Logic Reference (`analytics.vw_rfm_segmentation`)

Defined in `sql/03_rfm_segmentation.sql`, the RFM model evaluates every unique customer (`customer_unique_id`) using a 1-to-5 scoring system:
* **Recency Score (`r_score`):** `NTILE(5) OVER (ORDER BY recency_days DESC)` — Score `5` represents the most recent buyers.
* **Frequency Score (`f_score`):** Custom step function tailored to Olist's low repeat purchase distribution (`1 order = 1`, `2 orders = 2`, `3 orders = 3`, `4 orders = 4`, `5+ orders = 5`) to prevent `NTILE` bucket distortion.
* **Monetary Score (`m_score`):** `NTILE(5) OVER (ORDER BY monetary ASC)` — Score `5` represents the highest spenders.

| Segment Name | Classification Rule (`r_score`, `f_score`, `m_score`) | Strategic Meaning |
| :--- | :--- | :--- |
| **Champions** | `r_score >= 4 AND f_score >= 2 AND m_score >= 4` | High-spend repeat customers who bought recently. |
| **Loyal Customers** | `r_score >= 3 AND f_score >= 2 AND m_score >= 3` | Consistent repeat buyers with solid monetary contribution. |
| **Recent New Customers** | `r_score >= 3 AND f_score = 1` | Recently acquired one-time buyers with high onboarding potential. |
| **At Risk (Churning)** | `r_score <= 2 AND f_score >= 2` | Former repeat buyers who have not returned in a long time. |
| **Lost One-Timers** | `r_score <= 2 AND f_score = 1` | Inactive single-purchase customers with low reactivation probability. |
| **Regulars/Others** | `ELSE` | Customers with moderate spend/recency outside extreme tiers. |
